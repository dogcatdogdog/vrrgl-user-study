## 0. 结论摘要

> **数据源**：**自选数据集里 ≤110 节点的图**（26 张），**不做任何裁剪，用原生布局**
> **图数**：**16 张** —— 度数低档 8 张、高档 8 张
> **度数档**：低 = **2–8** 度 ／ 高 = **≥16** 度（**无上限**）
> **trial**：每任务 16，两个任务共 **32**（约 30–35 分钟）
> **不用 Rome**（除非作为稳健性检验的补充）

---

## 1. 为什么是这套 —— 三条硬约束

实验只做到**编码层**（「LPFD 的布局让邻域更好读」），不主张领域层（「对黑灰产分析有用」——那需要案例研究，已另议）。

在这个前提下，有三条硬约束依次排除了大部分选择：

| # | 约束 | 证据 |
|---|---|---|
| **C1** | **不能用子图裁剪** | 从整图布局里截出的 60 节点窗口，**局部几何被破坏**：seed 处的角均匀度实测只有 0.02–0.09（度 19 以上时四种方法全部塌到 0.00–0.05）。见 §2.1 |
| **C2** | **不能重新布局** | 本地不具备加载 LPFD 权重做推理的条件（`best_model.pth` 虽然存在，但运行环境不具备） |
| **C3** | **只能用原生尺寸合适的图** | 大图（case1–9，114–1079 节点）会导致认知负荷过重、任务地板 |

**C1+C2+C3 一起，把可选图源压到只剩：自选小图（26 张）+ Rome（1000 张）。**

## 2. 数据选择的判据

> ⚠️ **几何指标只能用来排除不可用的区间（地板 / 天花板），不能用来预测用户实验的效应大小。**

**为什么不能用来预测**：论文的核心论点正是「几何指标不能代表可读性」。**用一个已知不能代表可读性的量，去预测可读性实验的结果，是自相矛盾的。** 指标→人的映射关系**正是实验要测的东西**——不能用它自己的未知量去推断答案。

**所以本节的数据只服务于一个问题**：

> **哪些度数区间是「任务根本做不了」（地板）或「任务太容易」（天花板）？**

这两类区间必须排除。**落在可用区间内的效应大小，只能做了才知道。**

### 2.1 先排除裁剪（C1 的证据）

从整图布局里截 60 节点的 ego 窗口，在 seed 处的角均匀度：

| seed 度数 | LPFD | KK | FR | FA2 |
|---|---|---|---|---|
| 5–6 | **0.580 / 0.447** | 0.076 / 0.132 | 0.013 / 0.119 | 0.106 / 0.108 |
| 19–87 | 0.003–0.033 | 0.000–0.191 | 0.004–0.056 | 0.010–0.048 |

**低度数时 LPFD 大幅领先；一旦到 19 度以上，四种方法全部塌到 0.05 以下——谁都做不了。**

**结论：裁剪出的窗口在高档上是方法无关的地板，不可用。**

### 2.2 逐节点角均匀度，按度数分桶（**这是定档位的依据**）

角均匀度 = `最小相邻边夹角 ÷ (2π/度数)`，即论文 AR 公式里**单个节点的贡献项**（1 = 完全均匀，0 = 两条边重叠）。

**自选数据集（32 张，全部节点）**

| 度数桶 | 节点数 | LPFD | KK | FR | FA2 | **LPFD 优势** |
|---|---|---|---|---|---|---|
| 2–4 | 2791 | 0.5002 | 0.3675 | 0.3825 | 0.4824 | +0.0178（+3.7%） |
| **5–8** | 744 | **0.2087** | 0.0918 | 0.0631 | 0.1437 | **+0.0650（+45%）** ⭐ |
| 9–15 | 109 | 0.1621 | **0.1684** | 0.0858 | 0.0983 | **−0.0062（输）** |
| **16–25** | 69 | **0.1104** | 0.0747 | 0.0648 | 0.0529 | **+0.0357（+48%）** ⭐ |
| 26+ | 127 | 0.0228 | 0.0232 | 0.0109 | 0.0226 | −0.0003 |

**Rome-1000（300 张抽样，全部节点）**

| 度数桶 | 节点数 | LPFD | KK | FR | FA2 | **LPFD 优势** |
|---|---|---|---|---|---|---|
| 2–4 | 12056 | 0.6765 | 0.6428 | 0.6174 | 0.6483 | +0.0281（+4.4%） |
| 5–8 | 1358 | 0.3845 | 0.3685 | 0.2575 | 0.2776 | +0.0161（+4.4%） |
| 9–15 | **32** | 0.2297 | 0.2076 | 0.1595 | 0.1542 | +0.0221（+10.6%） |

### 2.3 这个指标**不能**用来排除任何度数区间

**关键：它取的是最小值，度量的是最坏情形，不是平均。」

```
角均匀度 = 最小相邻边夹角 ÷ 理想夹角        ← min，不是 mean
```

**所以「值低」只说明有一对边几乎重叠，不说明整个邻域糊；「值高」也不说明任务容易。**

> 下表的分桶（2–4 / 5–8 / 16–25 / 26+）是**测量时的分桶**，不是最终的度数档。最终档位见 §3.2。

| 度数区间 | 指标值 | ⚠️ **不能据此判定** |
|---|---|---|
| 2–4 | 0.50–0.68 | 0.68 也远不是「完美均匀」→ **不能判为天花板** |
| 5–8 | 0.21–0.38 | — |
| 16–25 | 0.11 | — |
| 26+ | 0.02 | 只说明**有一对边**重叠 → **不能判为地板** |

> **两次我都在用这个指标做取舍，两次都错。** 它既不预测效应大小，也不能判定任务可行性。
> **哪些区间可用，只能由 pilot 回答。**

### 2.4 那度数档根据什么定？

**只看两件事：对比度 + 供给。**

| 依据 | 说明 |
|---|---|
| **对比度** | H2 问的是「优势是否随度数变化」，所以两档的度数要**拉得开** |
| **供给** | 每个档位要有至少 8 张图可选（见 §5） |

**指标值不参与决策。**

### 2.5 Rome 的供给事实（与指标无关）

Rome 的度分布是 min 2、中位 7、**max 13** —— **它提供不了 16 度以上的节点**。

这是**供给事实**，不是效应判断。本设计的高档需要 ≥16 度的节点，**Rome 供不了**，所以数据源取自选。

## 3. 采用的方案

### 3.1 数据源：自选数据集里 ≤110 节点的图

```
来源：D:\VRRGL\data\dataset\benchmark_test_0312\
筛选：n ≤ 110 节点
数量：26 张
```

**不做任何裁剪。** 布局直接取自：

```
D:\VRRGL\data\eval_out\bench_pipeline_out_0612_ablation_2\graph_details\<graph>_layouts.json
```

那是**这些图自己的完整布局**（不是从大图里截的）。

### 3.2 度数档：**两档，均不设上限/下限的指标依据**

| 档位 | 度数范围 | 取法 |
|---|---|---|
| **低** | **2–8** | 图里度为 2–8 的节点 |
| **高** | **≥ 16**（**无上限**） | 图里度为 16 及以上的节点 |

**为什么是这两档 —— 只看对比度和供给：**

| 依据 | 说明 |
|---|---|
| **对比度** | H2 问的是「优势是否随度数变化」，所以两档的度数要**拉得开**。2–8 vs ≥16 最大差 16 倍 |
| **供给** | 低档：几乎每张图都有 2–8 度的节点；高档：**10 张图**可供（见 §5.2） |

**指标值不参与决策**（见 §2.3）。H2 会不会显著、两个档位会不会地板/天花板，**做了才知道**。

### 两处「不设限」的决定及其理由

| | 决定 | 理由 |
|---|---|---|
| **高档不设上限** | 26+ 度的图**保留** | 指标在 26+ 度上只有 0.02，但那是**最坏一对边**的度量（min），不代表整个邻域不可读 |
| **低档下限取 2** | 不排除低度节点 | 指标在 2–4 度上是 0.50–0.68，但 0.68 远不是「完美均匀」，**不构成天花板**。拒绝的是一个"看起来容易"的预判——**而那正是应该交给实验的问题** |

> **下限取 2 而不是 5**：取 5 会以「低度邻域太简单」为由主动截掉一段范围。既然论文的核心论点就是「几何指标不能代表可读性」，**就不该用指标去预先排除任何一段**。低度邻域到底会不会天花板，**pilot 说了算**。

**为什么只有两档**：三档会让每档图数不够（见 §5 供给），且 9–15 档在自选上 LPFD 是**输的**。

### 3.3 图数：**16 张**

```
每档 8 张 → 共 16 张

Latin square 核对：
  16 图 ÷ 4 布局 = 4  →  每布局覆盖 4 张 ✓ 整数，可平衡
  16 ÷ (4 布局 × 2 档) = 2  →  每个 (布局 × 度数档) 单元 2 张 ✓
```

### 3.4 trial 数

```
每任务 16 trial（每张图恰好出现一次）
两个任务共 32 trial
预计时长 30–35 分钟
```

## 4. 刺激构造流程（**比原方案简单很多**）

```
输入：data/dataset/benchmark_test_0312/*.json （46 个文件）
      data/eval_out/bench_pipeline_out_0612_ablation_2/graph_details/<graph>_layouts.json

步骤：
  1. 读所有图，筛出 n ≤ 110 的 → 26 张
  2. 对每张图，统计每个节点的度数
  3. 对每个度数档（低 2–8 ／ 高 ≥16）：
       · 从候选图里选出「含该档节点」的图
       · 每图挑 1 个该档的目标节点
         —— 2026-10-27 起用 `--target-rule mid`：低档取度 5 附近；
            高档按度数排序取中位名次，避开全图唯一的极端最大度
            （doc 未规定档内规则；旧版为 `top`，见 stimuli/README.md）
       · 按下列规则排序、取前 8 张（见 §4.2）
  4. 对每个 (图, 目标节点)，提取四种布局的坐标：
       LPFD ← "ablation_exp0_baseline"
       KK   ← "Kamada-Kawai"
       FR   ← "Fruchterman-Reingold"
       FA2  ← "ForceAtlas2"
     ⚠️ 坐标**原样使用**，不裁剪、不重新布局
  5. 匿名化（见 §5）
  6. 归一化（见 §4.3）
  7. 计算 ground truth（目标节点的一跳邻域）
  8. 输出 stimuli.json + stimuli/README.md
```

**注意：没有 ego 抽取这一步了。** 图本身就是刺激。

### 4.2 选图的确定性规则（必须逐位可复现）

```
① 候选排序键：按图名升序（保证跨机器一致）
② 每档取前 8 张
③ 排除规则（在排序后施加）：
     · 排除目标节点度数不落在档位区间的图
     · 若某张图在两档都被选中 → 允许（不同目标节点即可）
```

> ⚠️ **排序键里禁止出现浮点数比较**。`nx.betweenness_centrality` 一类算法的浮点结果依赖节点迭代顺序，跨进程会有 ULP 级差异，会导致**不同机器选出不同的 16 张图**。
> 若排序必须用浮点值：先 `round(x, 9)` 再排，并用字符串 id 作并列裁决。
> 参考实现见 `05_待讨论_溢出与措辞.md` 附录 B。

### 4.3 坐标归一化 —— **包围盒（fit-to-view）**

```
对每个 (图, 布局) 独立处理：
  1. 取该布局下所有节点的坐标
  2. 算包围盒 w × h（原坐标单位）
  3. 留白 = 画布尺寸的 8%（每边）⇒ 可用区 = 画布的 84%
  4. scale = min( (canvas_w × 0.84) / w,  (canvas_h × 0.84) / h )
  5. 缩放后把包围盒中心平移到画布中心
```

> ⚠️ **注意量纲**：留白必须从**画布像素**里扣，不能从**原坐标**里扣。
> 早期版本写作 `pad = 0.08 × max(w, h)` 再用 `(canvas_w − 2·pad)/w`，**把原坐标单位当像素减了** ——
> 实测会导致约 75% 的图裁掉边界节点。**正确做法是先算 scale，再乘 0.84。**
> （代码已按修正版实现，本文档此前是旧的。）

**画布 900 × 620**（GVRRI 规格，见 `01_平台设计.md` §2.3）。

**为什么是包围盒**：GVRRI 的 `resistance.py::plot_network`（包围盒 + 10%）、我们自己的 `paper_figure.py`（包围盒 + 8%）、以及用户「适应窗口」的真实体验——三个参照物全指向它。详见 `01_平台设计.md` §2.2。

**溢出不可能发生**，因此**不需要** shrink-to-fit、`k_min` 筛图、尺寸下限、自适应半径。

| `moviegalaxies-25` | 30 | 16 |

> ⚠️ **余量偏紧（只有 2 张）。** 若需要更多余量，可把高档放宽到 **16–30**（多出 `moviegalaxies-*` 里度 26–30 的节点）。

### 5.3 为什么不加 Rome

Rome 的相对优势只有 +4.4% ~ +10.6%，**比自选小 4–10 倍**。加进来只会稀释效应量、拉低测出差异的概率。

**若需要「数据来源不唯一」的稳健性证据**，建议：
- 用 Rome 跑一个小规模**补充实验**（不并入主实验），报告「方向是否一致」
- 而不是把 Rome 混进主实验的 16 张里

## 6. 匿名化规则

## 7. 已知弱点与应对

### 7.1 数据层面的弱点

| 弱点 | 应对 |
|---|---|
| **图族异质**（教材玩具图 + 电影共演 + 生态网络 + 网格图混在一起） | 在论文里如实报告；分析时**把图作为随机效应**（`(1\|graph)`），不当作固定因子 |
| **高档余量只有 2 张** | 见 §5.2 的放宽建议 |
| **自选小图里真的 hub 很少**（只有 10 张有 ≥16 度的节点） | 这是约束 C1–C3 的结果，如实报告 |

### 7.2 ⚠️ 三条必须在论文 Limitations 里报告的取舍

#### F1 — 跨任务图重复

| | |
|---|---|
| **取舍** | T1 与 T2 **共用同一批 16 张图、且共用同一份（图 → 布局）映射**。每被试 32 trial ⇒ 每张图见 **2 次，两次都是同一种布局** |
| **曾考虑的改进** | ❌ **已否决**：让 `offset_T4 = offset_T1 + 1`，使同一张图在两个任务里显示不同布局 |
| **否决理由** | 错位把「自我污染」换成「**交叉污染**」——T1 在 KK 下学到的结构会跑进 T4 的 FR 测量，不可归因。而同布局重复的偏差方向**可解释**（「读得懂才记得住」）。另外设计表述上「每人每图一种布局」一句话说得清 |
| **残留风险** | 被试在 T1 学到的图结构可能在 T4 迁移。方向是**抹平各布局差异**（保守偏差） |
| **缓解** | 任务分块（先 T1 后 T4 或反之，按 pid 交替）；两个任务问的是不同问题 |

#### F2 — 没有真正的 hub

| | |
|---|---|
| **取舍** | 刺激图的节点度数上限是 **25**（自选小图的限制） |
| **风险** | 论文第 1 章的动机描述是「一个 hub 节点有上百个邻居」——本实验**测不到那个尺度** |
| **缓解** | ① 论文里把「hub」的口径明确为**相对定义**（度数超过全图均值+一个标准差，与第 5 章的局部指标口径一致）；② 第 1 章的动机句需要相应收窄；③ 如实报告实验的尺寸边界 |

#### F3 — 未做用户实验的案例研究

| | |
|---|---|
| **取舍** | 本轮只做到**编码层**（「布局更好读」），不主张**领域层**（「对黑灰产分析有用」） |
| **后果** | 论文**不能**声称「对黑灰产分析有用」；标题里的 "Improving Node-Centric Readability" 是编码层主张，**可以成立** |
| **缓解** | 在 Limitations 里明确说明「领域层的验证留待后续」 |

### 7.3 与归一化相关的残留验证项

**pilot 必须同时产出一套「中位边长归一化」的刺激**，对比结论方向是否稳定。

```bash
python tools/build_stimuli.py --normalization bbox          # 主用
python tools/build_stimuli.py --normalization median_edge   # pilot 对比
```

若两套方向一致 → 归一化选择不影响结论，通过。
若不一致 → 说明存在尺度效应，**必须在论文里讨论**。

## 附录 A：文献依据（规模阈值）

| 研究 | 发现 |
|---|---|
| Yoghourdjian et al., TVCG 27(2):1677–1687, 2021 | 高密度 >50 节点、低密度 >100 节点，正确率跌破 50% |
| Saket, Kobourov & Pupyrev, GD 2014, LNCS 8871:234–245 | 交叉数效应在 40 节点显著、**120 节点不显著** |
| Ghoniem, Fekete & Castagliola, InfoVis 2004 | >20 节点 node-link 优势消失（路径任务除外） |
| Mooney et al., GD 2025, LIPIcs 357:38 | 实验图最大 50 节点；推测 >100 节点后效应很难影响人的表现 |

**综合：20–100 节点可靠可测；40–60 是「效应强 + 任务不平凡」的甜点区。** 本方案的 26 张图尺寸在 21–105，**全部落在有效区间**。
