# 数据导出指南

> 面向**跑实验的人**。写清楚：数据存在哪、怎么拿到、什么会弄丢、以及推荐的实验室流程。

---

## 0. 一句话

数据**不是自动存到磁盘的** —— 它存在浏览器的 `localStorage` 里。
你需要主动导出，否则清理浏览器数据就没了。

两种导出方式：

| 方式 | 何时用 |
|---|---|
| **`?export=all`** —— 一次性打包本机全部被试 | **实验室推荐**（一条命令把所有数据拿走） |
| **结束页的「下载我的数据」按钮** —— 单个被试 | 众包，或补导某一个人 |

---

## 1. 数据到底存在哪

```
浏览器 localStorage
  └─ 键名：vrrgl.data.<被试编号>      ← 每个被试一条，值是完整的 JSON
  └─ 键名：vrrgl.tabPid               ← 本标签页当前编号（sessionStorage）
  └─ 键名：vrrgl.labCounter           ← 自动编号计数器
  └─ 键名：vrrgl.pidIndex / counter   ← Latin square 的 offset 分配记录
```

**关键：localStorage 按「源」隔离**，也就是 `协议://主机:端口`。

- `http://127.0.0.1:8000` 和 `http://localhost:8000` 是**两个不同的源**，数据互不可见
- 端口换了（8000 → 8010）也是**另一个源**
- 换浏览器（Chrome → Edge）、用无痕窗口，都是空的

> ⚠️ **实验期间不要改网址**（`127.0.0.1` ↔ `localhost`、换端口），否则新打开的实验
> 看不到之前的数据，导出时也只会导出当前这个源的数据。

## 2. 方式 A：批量导出（实验室推荐）

### 步骤

1. 确保实验服务器还开着（`python tools/serve.py`）
2. 打开浏览器，地址栏输入：

   ```
   http://127.0.0.1:8000/src/?export=all
   ```

3. 浏览器会**自动下载**一个文件，文件名形如：

   ```
   vrrgl_all_sessions_2026-10-19.json
   ```

   默认落在「下载」文件夹（`C:\Users\<你>\Downloads\`）。

4. 页面上会同时列出本机所有被试的摘要，用来核对有没有遗漏：

   ```
   导出完成 / Export complete

   L001 — ✅ 已完成 — 48 trials（+ 2 attention）
   L002 — ⏳ 未完成 — 12 trials
   L003 — ✅ 已完成 — 48 trials

   共 3 位被试（其中 2 位已完成）
   ```

### 说明

- **包含未完成的会话**，会标 `⏳` —— 便于发现「有人做了一半就走了」，而不是静默丢掉
- **可以反复导出**，每次都会生成一个新文件（带日期），不会覆盖旧的
- 这个页面**不启动实验**，导完就停在那儿，关掉即可

## 3. 方式 B：单个被试（结束页按钮）

被试做完后会看到结束页，上面有一个 **「下载我的数据（JSON）」** 按钮，点了会下载
`<被试编号>.json`（例如 `L003.json`）。

适用于：
- 众包（Prolific）—— 被试自己下载后上传给你
- 漏掉了某一个人，单独补导

> 结束页上还会**醒目显示被试编号**，方便你把文件和人对上。

## 4. 导出文件长什么样

### 批量导出（`?export=all`）

```jsonc
{
  "exported_at": "2026-10-19T08:18:38.544Z",
  "count": 3,          // 本机被试总数
  "completed": 2,      // 其中已完成的
  "sessions": [        // 每个元素 = 一个被试，结构同单被试文件
    { ... }, { ... }, { ... }
  ]
}
```

`count: 0` 说明**当前这个源**没有数据 —— 见 §1 的「源隔离」。

### 单个被试

### 分析时最常用的字段

| 问题 | 取哪个字段 |
|---|---|
| 准确率 | T1 用 `jaccard`（连续，主指标）；T4 用 `correct`（0/1） |
| 反应时 | `rt_ms`（毫秒，整数）；`suspicious_rt = 1` 表示低于 `minRtMs`（默认 1s） |
| 自变量 | `layout`、`degree_level` |
| 随机效应 | `participant_id`（被试）、`graph_id`（图） |
| 质量控制 | `visibility_switches`、`attention.passed`、`suspicious_rt` |
| 协变量 | `demographics.graph_familiarity`、`demographics.graph_frequency` |
| 逐布局主观数据 | `per_trial_ease`（按 `trial_index` 与 trials 对应） |

## 5. 什么情况会丢数据

| 风险 | 说明 | 怎么防 |
|---|---|---|
| **清理浏览器数据** | 清缓存/Cookie/站点数据会一并清掉 localStorage | **每人做完就导一次**，或至少每天导 |
| **无痕 / 隐私窗口** | 关窗即清空 | 实验别用无痕窗口 |
| **换端口或主机名** | 不同源 = 不同数据 | 实验期间固定用同一个网址 |
| **换浏览器 / 换电脑** | 数据不互通 | 固定一台机器、一个浏览器 |
| **浏览器空间不足** | localStorage 可能被回收（少见） | 定期导出 |
| **`?pid=` 重复** | 同一编号会**续上**旧会话，看起来像数据缺失 | 实验室用无参数模式（自动编号） |

> **保守做法：每位被试做完就点一次 `?export=all`。** 文件很小（每人约几十 KB），
> 落在下载文件夹，不会影响后面的实验。

## 5.5 重置实验（重新从 L001 开始）

pilot 跑完、要开始正式实验时，打开：

```
http://127.0.0.1:8000/src/?reset=lab
```

| 按钮 | 作用 | 会不会删数据 |
|---|---|---|
| **① 先下载全部数据（推荐）** | 导出本机全部被试 | ❌ 不删，可重复点 |
| **② 清空全部数据，从 L001 重新开始** | 删除全部被试数据 + 重置编号 | ✅ 删（两次确认） |

**「保留 pilot 数据、正式实验从 01 开始」的正确做法**：先点 ① 把文件存好，再点 ②。

> 为什么没有「只重置编号、保留数据」这个选项：
> 数据是按**被试编号**存的，编号回到 L001 就会和旧的 L001 **撞号**，两份数据会被混在一起。
> 想两者都要，就只能先导出、再清空。

**防撞号**：即便编号被重置，系统在自动分配时会**跳过已存在的编号**
（若 `vrrgl.data.L001` 还在，下一位会自动跳到 L002），不会静默覆盖。

## 6. 推荐的实验室流程

```
实验开始前
  1. python tools/build_stimuli.py --check     # 确认刺激数据完好
  2. python tools/serve.py                     # 保持运行，别关
  3. 浏览器打开 http://127.0.0.1:8000/src/     # 注意：不带 ?pid=

每位被试
  4. 被试做完 → 结束页显示「被试编号：L00X」→ 记到纸质记录上
  5. 关掉标签页

每位（或每天）
  6. 打开 http://127.0.0.1:8000/src/?export=all
  7. 把下载的 vrrgl_all_sessions_<日期>.json 拷到安全位置（移动硬盘 / 云端）
  8. 核对页面摘要：人数对不对？有没有 ⏳ 未完成的？
```

> 建议同时保留**纸质/电子记录表**（编号 ↔ 姓名，仅用于发报酬），
> 与研究数据分开存放 —— 这与知情同意书 §10 的承诺一致。

## 7. 想自动落盘？（可选，需要小后端）

默认的 `localStorage` 模式不需要服务器，适合实验室。

如果希望**每做完一题就自动发到服务器**（例如众包，或不想手动导出），可以切到 POST 模式：

```js
// src/js/config.js
storage: { mode: 'post', endpoint: 'http://127.0.0.1:5000/submit', autosaveEveryTrial: true }
```

然后跑一个接收 JSON 的小后端（任何框架都行，收到后按 `participant_id` 存文件）。
**注意**：POST 失败时数据仍会保存在本地 `localStorage`（不会丢），但控制台会报错 ——
众包场景下建议同时保留导出作为兜底。

## 8. 常见问题

**Q：打开 `?export=all` 显示「共 0 位被试」，但明明做过？**
A：你换过网址。检查是不是 `localhost` 和 `127.0.0.1` 混用，或端口变了（见 §1）。

**Q：导出的 JSON 里 `trials` 只有 54 条，但设计是 32 试次？**
A：54 = 4 练习 + 32 正式 + 2 attention。分析时按 `phase` 过滤：
- `phase === 'main'` → 32 条正式试次
- `phase === 'practice'` → 4 条练习（**不要计入分析**）
- `phase === 'attention'` → 2 条理解力检查

**Q：`literacy` 为什么是 null？**
A：图素养前测已取消（`docs/03 §6.3`），这是预期行为。

**Q：`config.locale` 是做什么的？**
A：记录这位被试实际看到的是哪种语言界面，方便核对中英文数据是否混在一起。
